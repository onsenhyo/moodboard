# 무드보드 2차: 묶음 상자와 캔버스 디자인

작성일 2026-11-15 · 상태: 사용자 승인 대기 · 1차 설계: `2026-11-14-moodboard-design.md`

## 1. 왜
사용자가 실제 창을 써 보고 남긴 피드백 두 가지를 반영한다.
- "폴더 같은 걸 두고 자료를 넣고 싶다."
- "캔버스가 전체적으로 안 예쁘다. 사진 모서리의 라운드 처리를 빼 달라."

## 2. 결정된 것 (사용자)
- 폴더 모양은 **A안, 캔버스 위 묶음 상자**로 한다.
- 색 정렬은 **전체를 한 번에** 정렬한다. 정렬하는 동안 묶음 상자는 숨긴다.
- 테마
  - 쉘이 라이트 테마면 **A "갤러리·따뜻한 종이"**, 다크 테마면 **B "다크 스튜디오"**로 그린다.
  - 시스템 테마면 OS 설정을 따르고, 바뀌는 즉시 다시 그린다.
- 사진 카드는 **모서리를 각지게** 그린다(라운드 없음). 두 테마 모두 같다.
- 시안: `docs/mockups/canvas-style-options.html`의 A, B.

## 3. 묶음 상자
- 데이터
  - `Board.groups: Group[]`, 각 Group은 `{id, name, rect:{x,y,w,h}, collapsed:boolean, updatedAt, deleted?}`이다.
  - 카드에는 `groupId?: string`이 붙는다.
  - 병합과 묘비 규칙은 카드와 같다(id별로 updatedAt이 큰 쪽).
- 만들기: 툴바의 [묶음 추가]를 누르면 화면 가운데에 `새 묶음` 상자(400×300)가 생긴다.
- 넣고 빼기: 카드를 끌어 놓을 때 카드 중심이 어떤 묶음의 rect 안이면 그 묶음에 넣는다. 밖이면 `groupId`를 지운다. 여러 묶음이 겹치면 위에 그려진 묶음에 넣는다.
- 상자 조작
  - 제목줄을 끌면 상자와 안의 카드가 함께 움직인다.
  - 모서리를 끌면 상자 크기만 바뀐다. 최소 크기는 160×100이다.
  - 제목줄의 ▾/▸를 누르면 접히고 펼쳐진다. 접히면 제목줄만 보이고 안의 카드는 숨는다.
- 선택: 상자를 누르면 옆 칸에서 이름 바꾸기와 [묶음 삭제]를 할 수 있다. 삭제해도 안의 카드는 남고, 카드의 `groupId`만 지운다.
- 그리는 순서: 묶음 상자를 맨 아래에 그리고 카드를 그 위에 그린다.
- 색 정렬 모드: 상자를 숨기고 모든 카드를 기존 규칙대로 정렬한다. [내 배치]로 돌아오면 원래대로 보인다.
- 내보내기: 내보낸 페이지에도 묶음 상자가 같은 스타일로 보인다. 접힌 상자는 접힌 채로 내보낸다.

## 4. 캔버스 디자인 토큰
| 요소 | 라이트 (A) | 다크 (B) |
|---|---|---|
| 바탕 | `#f4f1ec` 단색 | `#141416` + 18px 점 격자 `#2a2a2e` |
| 사진 카드 | 흰 매트(6px, 아래 22px)·각진 모서리·그림자 2겹 | 여백 없이 꽉 참·각진 모서리·그림자 `0 10px 30px rgba(0,0,0,.6)` |
| 사진 캡션 | 매트 아래쪽에 종류(youtube/pinterest/image/video), Georgia 11px `#666` | 없음 |
| 종류 배지 | 흰 반투명 칩, 글자 `#555` | 검은 반투명 칩, 글자 `#eee` |
| 글 카드 | `#fffdf7`, Georgia 이탤릭 13px `#3a352d` | `#232327`, 시스템 글꼴 13px `#e9e6df`, 왼쪽 3px 색 띠 |
| 묶음 상자 | 1px `#cfc7ba` 선, 흰 35% 채움, 이름은 Georgia 대문자 11px `#8a7f6e`(상자 위쪽 바깥) | 흰 4% 채움, 흰 10% 선, 이름은 시스템 글꼴 11px `#bdbdc4` + 대표 색 점 |
| 선택 표시 | 2px `#3a352d` 바깥선 | 2px `#e9e6df` 바깥선 |
| note 띠 | 카드 아래 반투명 띠 | 같음 |

- 묶음의 대표 색 점은 안에 든 카드 대표 색의 hue 중앙값으로 정한다. 비어 있으면 회색.
- 둥근 모서리는 쓰지 않는다. 배지 칩도 각진 사각형이다.
- 내보낸 페이지는 열어 보는 사람 브라우저의 `prefers-color-scheme`에 따라 A/B를 고른다.

## 5. 플랫폼 확인 필요
- client 프레임 안의 `matchMedia('(prefers-color-scheme: dark)')`가 쉘 테마 설정(Tauri `window.set_theme`)을 따라 바뀌는지는 아직 확인하지 않았다. 첫 단계에서 실제로 확인한다.
- 안 바뀌면 다음 순서로 대안을 찾는다.
  1. 쉘이 frame에 테마를 전달하는 다른 경로를 찾는다.
  2. 없으면 앱 설정에 [자동/라이트/다크] 선택을 두고 사용자에게 알린다.

## 6. 범위 밖
- 쉘 블록(툴바·옆 칸·입력칸)의 모양은 바꿀 수 없다.
- 휠 줌과 핀치는 canvas가 받지 않아 지원하지 않는다.
